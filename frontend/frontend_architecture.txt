# Architecture Frontend - Refonte Complète

## 🎯 **Vision produit**

Interface moderne centrée sur l'**intelligence artificielle** et la **surveillance proactive** des affaires guadeloupéennes.

**Principe clé :** L'IA guide l'utilisateur vers les informations importantes plutôt que de noyer dans la masse.

---

## 🛠️ **Stack Technique Recommandée**

### **Framework : Next.js 14 + TypeScript**
- **Pourquoi :** Server-side rendering, performance, écosystème React mature
- **App Router** pour la nouvelle structure de fichiers
- **Streaming** pour les données en temps réel

### **Styling : Tailwind CSS + shadcn/ui**
- **Pourquoi :** Système de design cohérent, composants pré-construits
- **shadcn/ui** pour les composants complexes (charts, tables, modals)
- **Lucide Icons** pour l'iconographie

### **State Management : Zustand + TanStack Query**
- **Zustand** : État global simple et performant
- **TanStack Query** : Cache intelligent des données API, synchronisation

### **Visualisations : Recharts + D3.js**
- **Recharts** : Graphiques standards (barres, lignes, aires)
- **D3.js** : Visualisations custom (heatmaps, network graphs)
- **Plotly.js** : Graphiques 3D si nécessaire

### **Real-time : Socket.io ou SSE**
- Pour les notifications d'alertes critiques
- Mise à jour des dashboards en temps réel

## 🔄 **Flux de données temps réel**

### **WebSocket Events**
```typescript
interface WebSocketEvents {
  'scraping:started': { timestamp: string };
  'scraping:completed': ScrapingResponse;
  'affair:created': { affair: Affair };
  'affair:updated': { affair: Affair };
  'social:alert': { alert: CriticalAlert };
  'sentiment:updated': { affair_id: string; metrics: SentimentMetrics };
}
```

### **TanStack Query Keys**
```typescript
const queryKeys = {
  articles: ['articles'] as const,
  articlesByDate: (date: string) => ['articles', date] as const,
  affairs: ['affairs'] as const,
  affairDetails: (id: string) => ['affairs', id] as const,
  socialMetrics: (id: string) => ['social', 'metrics', id] as const,
  sentimentChart: (id: string, days: number) => ['sentiment', 'chart', id, days] as const,
};
```

## ⚡ **Optimisations Performance**

- **Code splitting** par route
- **Lazy loading** des composants lourds
- **Virtual scrolling** pour les listes longues
- **Memoization** des calculs complexes
- **Service Worker** pour cache offline
- **CDN** pour assets statiques

---

## 🔒 **Sécurité & Auth**

- **JWT** avec refresh token
- **Role-based access** (admin, viewer)
- **Rate limiting** côté client
- **Validation** Zod sur tous les formulaires
- **Sanitization** des données affichées
